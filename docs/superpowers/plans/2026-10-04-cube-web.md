# Superset browser entry implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Serve Superset's actual workspace renderer as a Cube app without display streaming.

**Architecture:** Preserve the existing backend runtime and add a loopback browser transport. Reuse the renderer and host-service with a small browser compatibility layer. Keep Superset account authentication and persistent data.

**Tech Stack:** TypeScript, React, Electron backend, tRPC, Node HTTP/WebSocket, Vite, Cube app gate.

**Spec:** `docs/superpowers/specs/2026-10-04-cube-web-design.md`

## Global Constraints

- No VNC, video frames, screenshots, or remote desktop input forwarding in the app UI.
- Preserve existing upstream renderer behavior and account authorization.
- Bind to loopback; authenticate through Cube's gate; validate origins; proxy only coordinator-owned host services and the fixed Superset API.
- Use isolated data for development; preserve installed app data and live sessions.
- Keep desktop mode functional when browser mode is absent.

## Review Focus

- A sibling app origin must not invoke desktop procedures or open sockets.
- Port forwarding must not become arbitrary localhost access.
- Refresh/reconnect must retain terminal state without duplicate commands.
- Cloud paths with spaces and invalid paths must produce usable folder selection behavior.
- Shutdown must spare unrelated processes and preserve persistent state.

### Task 1: Browser server and backend lifecycle

**Files:** `apps/desktop/src/main/browser-host/`, `apps/desktop/src/main/index.ts`, `apps/desktop/src/main/windows/main.ts`, `apps/desktop/src/lib/electron-app/factories/windows/create.ts`.

**Interfaces:** Expose the existing AppRouter over `/__cube/trpc` and a WebSocket subscription endpoint; serve renderer assets; proxy `/__cube/host/<port>/...` only for coordinator-owned ports. Browser mode is opt-in with launcher-owned configuration.
